# Existential Dread Scheduling Assistant

A revolutionary smart contract system that optimizes mortality awareness through strategic life-questioning calendar integration.

## Overview

The Existential Dread Scheduling Assistant is a blockchain-powered platform designed to help users confront their deepest existential anxieties through systematic scheduling and perspective management. By leveraging the immutable nature of smart contracts, users can commit to facing their mortality awareness in a structured, meaningful way.

## System Architecture

This system consists of two primary smart contracts working in harmony:

### 1. Quarter Life Crisis Trigger Scheduler
- **Purpose**: Automatically books daily reminders about unfulfilled dreams and ticking biological clocks
- **Features**:
  - Personalized crisis scheduling based on user age and life goals
  - Automated reminder generation for unfulfilled aspirations
  - Biological clock awareness notifications
  - Progress tracking for existential milestone management

### 2. Cosmic Insignificance Perspective Engine
- **Purpose**: Provides real-time scale comparisons between your problems and the heat death of the universe
- **Features**:
  - Universal scale perspective calculations
  - Problem significance ratio analysis
  - Cosmic timeline contextual framing
  - Existential comfort through statistical insignificance

## Development Setup

```bash
# Install Clarinet
curl -L https://github.com/hirosystems/clarinet/releases/latest/download/clarinet-linux-x64.tar.gz | tar xz

# Clone and setup
git clone <repository-url>
cd Existential-Dread-Scheduling-Assistant
clarinet check

# Run tests
clarinet test

# Deploy to testnet
clarinet deploy --network testnet
```
